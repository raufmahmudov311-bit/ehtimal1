Ehtimal nəzəriyyəsi · Mövzu 1

Ehtimalın əsas xassələri

Əsas anlayışlar, hadisələr, Kolmoqorov aksiomları, statistik və klassik ehtimal, kombinatorika. Əvvəl nəzəriyyəni oxu, sonra səhifənin sonundakı imtahan tipli testlə özünü yoxla.

Statistik ehtimalı özün gör

Zər at: «6» gəlmə tezliyi atışlar çoxaldıqca nəzəri 1/6 dəyərinə (qırıq xətt) yaxınlaşır.

1. Əsas anlayışlar

Təsadüfi təcrübə (sınaq) — eyni şəraitdə təkrar oluna bilən və nəticəsi əvvəlcədən dəqiq bilinməyən hərəkətdir (zər atmaq, kartı çəkmək).

Elementar hadisə (ω) — təcrübənin ən sadə, daha bölünməyən nəticəsi. Bütün elementar hadisələrin çoxluğu elementar hadisələr fəzası Ω adlanır. Zər üçün Ω = {1, 2, 3, 4, 5, 6}.

Hadisə (A, B, C…) — Ω-nın istənilən alt çoxluğudur. Məsələn, «cüt xal gəldi» A = {2, 4, 6}. Təcrübə nəticəsində ω ∈ A olarsa, A hadisəsi baş verib.

2. Hadisələr üzərində əməllər

ƏməlYazılışıMənası
Birləşmə (cəm)A ∪ B  (A + B)A və ya B (ən azı biri) baş verir
Kəsişmə (hasil)A ∩ B  (AB)A və B birlikdə baş verir
FərqA \ BA baş verir, B baş vermir
TamamlayıcıAA baş vermir
A ∪ B = B ∪ A  ·  A(B ∪ C) = AB ∪ AC  ·  A ∪ A = Ω  ·  AA = ∅

De Morqan qaydaları (ən çox soruşulan eyniliklər):

A ∪ B = A ∩ B   |   A ∩ B = A ∪ B
Yadda saxla: üst xətt çəkəndə «və ↔ və ya» dəyişir. «Heç biri baş vermədi» = AB.

3. Kolmoqorov aksiomları

Ehtimal fəzası üç elementdən ibarətdir: Ω, hadisələr sistemi F (hadisələr cəbri/σ-cəbr) və hər A ∈ F hadisəsinə uyğun gələn P(A) ədədi. P aşağıdakı üç aksiomu ödəməlidir (A. N. Kolmoqorov, 1933):

A1 (mənfi olmama): P(A) ≥ 0
A2 (normallıq): P(Ω) = 1
A3 (additivlik): AB = ∅ olarsa, P(A ∪ B) = P(A) + P(B)

Sonsuz sayda cüt-cüt uyğunsuz A₁, A₂, … üçün A3 genişlənir: P(⋃Aᵢ) = ΣP(Aᵢ) (σ-additivlik).

Aksiomlarının ehtimal nəzəriyyəsinin inkişafında rolu. Kolmoqorovdan əvvəl ehtimalın klassik, statistik və həndəsi təriflərinin hər birinin məhdudiyyəti var idi (məsələn, klassik tərif yalnız bərabər mümkün sonlu hallar üçündür). Aksiomatika «ehtimal nədir?» sualına yox, «ehtimal hansı qaydalara tabedir?» sualına cavab verdi: bütün köhnə təriflər onun xüsusi halına çevrildi. Nəticədə ehtimal nəzəriyyəsi çoxluqlar nəzəriyyəsi və ölçü nəzəriyyəsi üzərində ciddi riyazi elm oldu, təsadüfi proseslər və riyazi statistika onun əsasında qurulur.

4. Ehtimalın xassələri

Hamısı yalnız A1–A3-dən çıxır.

Xassəİsbatın ideyası
1. P(∅) = 0Ω = Ω ∪ ∅, uyğunsuzdur ⇒ 1 = 1 + P(∅)
2. P(A) = 1 − P(A)A ∪ A = Ω, uyğunsuzdur ⇒ P(A) + P(A) = 1
3. A ⊂ B ⇒ P(A) ≤ P(B), P(B \ A) = P(B) − P(A)B = A ∪ (B \ A), uyğunsuzdur; P(B\A) ≥ 0
4. 0 ≤ P(A) ≤ 1A ⊂ Ω olduğundan 3-cü xassədən
5. P(A ∪ B) = P(A) + P(B) − P(AB)A ∪ B = A ∪ (B \ AB), P(B\AB) = P(B) − P(AB)
6. Tam qrup: P(A₁) + … + P(Aₙ) = 1A3 və P(Ω) = 1
P(A ∪ B ∪ C) = P(A)+P(B)+P(C) − P(AB) − P(AC) − P(BC) + P(ABC)
Tipik səhv: uyğun hadisələr üçün P(A ∪ B) = P(A) + P(B) yazmaq. Bu yalnız AB = ∅ olduqda doğrudur. Eyni zamanda P(A ∪ B) ≤ P(A) + P(B) həmişə doğrudur.

5. Statistik ehtimal

Təcrübə n dəfə təkrar edilir, A hadisəsi m dəfə baş verir. Nisbi tezlik:

W(A) = m / n

Təcrübələr çoxaldıqca W(A) müəyyən ədəd ətrafında dayanıqlaşır (tezliyin sabitliyi). Bu ədəd A-nın statistik ehtimalı sayılır: P*(A) ≈ W(A) (böyük n üçün).

Nisbi tezlik də 0 ≤ W(A) ≤ 1, W(Ω) = 1, W(∅) = 0 şərtlərini və uyğunsuz hadisələr üçün additivliyi ödəyir, buna görə aksiomlara uyğundur.

Çatışmazlığı: təcrübə lazımdır, nəticə hər seriyada bir az fərqlənir, dəqiq ədəd vermir. Üstünlüyü: bərabər mümkünlük tələb etmir (məsələn, qüsurlu məhsul faizi, hava proqnozu).

6. Klassik ehtimal

Tutaq ki, Ω sonlu və n sayda bərabər mümkün, cüt-cüt uyğunsuz nəticədən ibarətdir. A hadisəsinə m nəticə əlverişlidir. Onda:

P(A) = m / n   (əlverişli hallar / bütün mümkün hallar)

Şərtlər: (1) nəticələrin sayı sonludur, (2) hamısı bərabər mümkündür. Bu şərtlərdən biri pozulsa, tətbiq etmək olmaz (məsələn, «iki zərin cəmi» 2…12 kimi 11 nəticə bərabər mümkün deyil, 36 cütdən istifadə etmək lazımdır).

Nümunə: iki zər atılır, cəmi 7. Əlverişli cütlər: (1,6),(2,5),(3,4),(4,3),(5,2),(6,1), yəni m = 6, n = 36, P = 1/6.

Xassələri: P(Ω)=1, P(∅)=0, 0≤P(A)≤1, uyğunsuzlar üçün additivlik, yəni klassik ehtimal Kolmoqorov aksiomlarını ödəyir.

7. Kombinatorika elementləri

Vurma qaydası: birinci seçim n₁, ikinci n₂ üsulladırsa, ardıcıl seçim n₁·n₂ üsulladır. Toplama qaydası: «ya bu, ya o» seçimində üsullar toplanır.

AnlayışDüsturNə vaxt
PermutasiyaPₙ = n!n elementin hamısı düzülür, sıra vacibdir
YerləşdirməAₙᵏ = n!/(n−k)!n-dən k seçilir, sıra vacibdir
BirləşməCₙᵏ = n!/(k!(n−k)!)n-dən k seçilir, sıra vacib deyil
Təkrarlı yerləşdirmənᵏhər dəfə n-dən seçilir, təkrar olur
Təkrarlı permutasiyan!/(n₁!n₂!…)n₁, n₂, … eyni elementlər var
0! = 1  ·  Cₙᵏ = Cₙⁿ⁻ᵏ  ·  Cₙ⁰ = Cₙⁿ = 1  ·  Cₙ¹ = n  ·  Aₙᵏ = Cₙᵏ · k!
Qayda: «Sıra vacibdir?» sualını ver. Bəli → Aₙᵏ (və ya Pₙ). Xeyr (qrup, komanda, kürələr dəstəsi) → Cₙᵏ.

8. Klassik tərif vasitəsilə iki ümumi məsələ

Məsələ 1. Seçmə (hipergeometrik sxem)

N elementdən M-i «xüsusi»dir (məsələn, ağ kürə, qüsurlu detal). Təsadüfi n element seçilir. Seçilənlər arasında düz k xüsusi element olması ehtimalı:

P = Cₘᵏ · CN−Mn−k / Cₙᴺ   (bütün hallar CNn)

Məxrəc: N-dən n seçmə sayı. Surət: M-dən k xüsusini və qalan N−M-dən n−k adini seçmək (vurma qaydası). Əks hadisə üsulu: «ən azı biri» = 1 − «heç biri».

Məsələ 2. Hissəciklərin xanalara paylanması

n müxtəlif hissəcik N xanaya təsadüfi paylanır. Hər hissəcik N xanadan istənilənə düşə bilər, ona görə bütün hallar Nⁿ.

Hər xanada ən çox 1 hissəcik: P = Aₙᴺ / Nⁿ = N(N−1)…(N−n+1) / Nⁿ

Eyni sxemlə ad günü məsələsi həll olunur: n nəfərdən heç ikisinin ad günü üst-üstə düşmür, N = 365. n = 23 üçün bu ehtimal 0,5-dən kiçikdir, yəni üst-üstə düşmə ehtimalı ≈ 0,507-dir.

9. Həll olunmuş nümunələr

Nümunə 1. Qutuda 5 ağ, 3 qara kürə var. 2 kürə çəkilir. Biri ağ, biri qara olması ehtimalı?

n = C₈² = 28. Əlverişli: C₅¹·C₃¹ = 15. P = 15/28 ≈ 0,536.

Nümunə 2. P(A)=0,6, P(B)=0,5, P(A∪B)=0,8. P(AB) = ?

Toplama teoremi: 0,8 = 0,6 + 0,5 − P(AB) ⇒ P(AB) = 0,3. Yoxlama: P(AB) ≤ min(P(A),P(B)) = 0,5 ✓.

Nümunə 3. 3 nəfər təsadüfi 12 aydan birində doğulur. Doğum aylarının hamısı müxtəlif olması ehtimalı?

Bütün hallar 12³ = 1728; əlverişli A₁₂³ = 12·11·10 = 1320. P = 1320/1728 = 55/72 ≈ 0,764.

Nümunə 4. 52 kartdan 1 kart çəkilir. Ürək və ya kral gəlməsi?

Ürək 13, kral 4, ürək kralı həm ikisidir (1). Ümumi hal: P = 13/52 + 4/52 − 1/52 = 16/52 = 4/13.

10. Özünü yoxla

İki rejim var. Məşq rejimində cavab verən kimi izah görünür. İmtahan rejimində 12 təsadüfi sual və 20 dəqiqə var, nəticə sonda açılır. Praktiki məsələlərin cavabını kəsr (1/3) və ya onluq kəsr (0,3333) şəklində yaz, 3 rəqəm dəqiqlik yetərlidir.
